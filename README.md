# 🎫 Automated Ticket Classifier

An end-to-end machine learning project designed to automatically classify customer support tickets into relevant categories using **Natural Language Processing (NLP)** and **Machine Learning(logistic regression)**.

The goal of this project is to build a practical support-ticket automation system that can understand incoming customer complaints or requests and automatically route them to the appropriate category.

> 🚧 **Project Status:** In Progress  
> Currently working on Exploratory Data Analysis (EDA) and understanding the support-ticket dataset. The machine learning model and web application will be developed progressively.

---

## 🎯 Project Goal

Customer support teams receive large numbers of tickets every day.

Manually reading and categorizing every ticket can be time-consuming and may lead to delays in routing requests to the appropriate team.

This project aims to build an automated system that can:

**Customer Ticket → NLP Processing → ML Model → Predicted Category → Automated Routing**

The final system is planned to accept a support ticket through a web interface and automatically predict its category.
